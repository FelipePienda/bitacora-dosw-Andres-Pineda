# Semana 1: Streams y Git Flow

## Evidencia Técnica
- **Rama de trabajo:** `feature/semana1-streams`
- **Temas vistos:** Java Stream API (filter, map, sorted, collect, peek, anyMatch) y GitFlow.

## Ejercicios Resueltos
1. **Filtro Números:** Pares > 10.
2. **Procesamiento de Palabras:** Filtro > 4 letras, Uppercase y Sort.
3. **Usuarios Activos:** Filtrado por estado y mapeo de nombres.
4. **Mayores de Edad:** Uso de filtros por atributo edad.
5. **Transacciones:** Validación de lotes con `anyMatch` y monitoreo con `peek`.

## Autoevaluación
* **¿Qué entendía mal antes?** - Pensaba que para filtrar y transformar una lista era obligatorio usar ciclos `for` y `if` anidados, lo cual hacía el código muy largo.
* **¿Qué entiendo ahora?** - Entiendo que los Streams permiten procesar datos de forma declarativa, haciendo el código más legible y eficiente mediante tuberías (pipelines).
* **¿Qué me falta reforzar?** - Me falta practicar más el uso de `Collectors` más complejos y entender mejor las referencias a métodos (`::`).
